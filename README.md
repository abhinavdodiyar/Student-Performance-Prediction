
# Student Performance Prediction

## Project Overview
A Machine Learning project that predicts student
marks out of 100 and assigns a grade and result.

## Objectives
- Predict estimated final marks.
- Assign grades from P to O.
- Display PASS or FAIL.

## Dataset
UCI Student Performance Dataset:
https://archive.ics.uci.edu/dataset/320/student+performance

## Algorithm
Random Forest Regression

## Input Features
- Study time per week
- Previous failures
- Absences
- First period marks (G1)
- Second period marks (G2)

## Output
- Predicted marks out of 100
- Grade
- PASS or FAIL

## Grading Rules
- Below 35: FAIL
- 35 to 39: P
- 40 to 49: C
- 50 to 59: B
- 60 to 69: B+
- 70 to 79: A
- 80 to 89: A+
- 90 to 100: O

## Technologies
- Python
- Google Colab
- Pandas
- Scikit-learn

## How to Run
Open the notebook in Google Colab.
Run each code cell in order.

## Disclaimer
This is an educational prediction model.
Its predictions are estimates, not guarantees.
